1. Unidades

1.1 Números, comprimentos e porcentagens

Existem vários tipos de valores numéricos. Por exemplo:

Tipo de dado Descrição
<integer> Um valor inteiro. Ex.: 10, -20, 542.
<number> Um valor decimal. Ex.: 1.2, 10, 0.25.
<dimension> Consiste em um <number> com uma unidade de medida. Ex.: 45deg, 10px.
<percentage> Representa uma fração de outro valor. Ex.: 50%.

1.1.1 Comprimentos

É o tipo numérico <length>. Existem dois tipos: absoluto e relativo.

Unidades de comprimento absoluto

São unidades de medida que não são relativas a nenhuma outra, e são geralmente consideradas serem sempre do mesmo tamanho.

Unidade Nome Equivalência
cm Centímetros 1cm = 37.8px = 25.2/64in
mm Milímetros 1mm = 1/10 * 1cm
Q Quartos de milímeros 1Q = 1/40 * 1cm
in Inches (Polegadas) 1in = 2.54cm = 96px
pc Picas 1pc = 1/6 * 1in
pt Pontos 1pt = 1/72 * 1in
px Pixels 1px = 1/96 * 1in

Unidades de comprimento relativo

São sempre relativos a alguma coisa. Por exemplo:

  • em é relativo ao tamanho da fonte do elemento em questão, ou em relação ao seu pai.
  • rem é relativo ao tamanho da fonte do elemento raiz (<html>).
  • vh e vw são relativos à altura (heigt) e largura (width) do viewport, respectivamente.

A vantagem de se usar unidades relativas é que o tamanho dos elementos são escalados automaticamente. Uma lista completa das unidades disponíveis pode ser encontrado em <length>.

Exemplo:

Eu tenho 200px de comprimento
Em tenho 10vw de comprimento
Eu tenho 10em de comprimento

1.2 Cores

O sistema de cores padrão atual nos computadores modernos suporta cores de 24bits, o que permite a exibição de cerca de 16,7 milhões de cores, através da combinação de três canais (red, green e blue) de 256 cores (256 x 256 x 256 = 16.777.216).

As formas mais comuns de se especificar as cores com CSS são: palavras-chave, hexadecimal e rgb().

1.2.1 Palavras-chave

Essas palavras-chave são nomes que foram dados a determinadas cores. Exemplo:

antiquewhite
blueviolet
greenyellow

1.2.2 Hexadecimal

#02798b
#c55da1
#128a7d

1.2.3 RGB

rgb(2 121 139)
rgb(197 93 161)
rgb(18 138 125)

2. Web design responsivo

Ou Responsive web design (RWD) é uma abordagem de design web para fazer páginas web renderizarem bem em todos os tamanhos e resoluções de tela, ao mesmo tempo em que garante uma boa usabilidade.

Por padrão o HTML já é responsivo, pois vai procurar acomodar os conteúdos de acordo com o viewport. Entretanto, supondo o caso de um longo trecho de texto, este pode ficar difícil de ser lido. Com o uso de CSS esse problema pode ser resolvido ao se diminuir o tamanho das colunas de texto. Porém, essa solução pode acabar criando novos problemas, dessa vez para usuários que estejam acessando ao conteúdo a partir de dispositivos móveis, de forma que as colunas fiquem muito finas, atrapalhando a leitura.

O RWD vem como uma solução para problemas dessa tipo, ao permitir adaptação automática da tela. Ele consiste em uma abordagem, ou seja, um conjunto de boas práticas para a criação de layouts que possam responder a qualquer dispositivo que esteja sendo usado.

O termo responsive design foi cunhado por Ethan Marcotte em 2010, descrito usando grades e imagens fluidas, e consultas de mídia (media queries) para a criação de conteúdo responsivo.

Os métodos de layout modernos do CSS são inerentemente responsivos e, desde a publicação do artigo do Ethan Marcotte, várias funcionalidades foram adicionadas para facilitar a construção de sites responsivos. Exemplos:

  • Media Queries;
  • Tecnologias de layout responsivas;
  • Imagens/mídia responsivas;
  • Tipografia responsiva;
  • A meta tag viewport.
