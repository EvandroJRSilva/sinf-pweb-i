Cinco sistemas, um documento

Este arquivo é autocontido: um único HTML com CSS embutido demonstrando os cinco mecanismos de layout do CSS — fluxo normal, floats, position, flexbox e grid — cada um com os casos de uso mais comuns. Abra o código para ver exatamente qual propriedade produz qual efeito.

01

Fluxo normal (Normal Flow)

É o comportamento padrão: elementos block empilham verticalmente ocupando toda a largura disponível; elementos inline fluem horizontalmente dentro do texto; inline-block flui como inline mas aceita largura, altura e margens verticais.

display: block
bloco 1 — ocupa 100% da largura
bloco 2 — quebra de linha automática
bloco 3 — empilhado verticalmente
display: inline
Este parágrafo contém um trecho inline que flui junto com o texto normalmente, sem provocar quebra de linha — largura e altura não têm efeito aqui.
display: inline-block
card Acard Bcard Ccard D — largura fixa, quebra ao faltar espaço 
.block       { display: block; }
.inline      { display: inline; }
.inline-block{ display: inline-block; width: 90px; }
02

Floats

Originalmente pensado para envolver texto ao redor de imagens; também foi usado (antes do flexbox/grid) para construir colunas. Elementos flutuantes saem do fluxo normal e exigem clearfix para não "vazar" sobre o conteúdo seguinte.

float: left — texto envolvendo uma imagem
figura.png

Quando um elemento recebe float: left, ele é retirado do fluxo normal e empurrado para a esquerda; o conteúdo em fluxo normal que vem depois — como este parágrafo — flui ao redor dele, preenchendo o espaço restante à direita, exatamente como em uma diagramação de jornal ou revista impressa.

float: left — colunas (técnica legada) + clearfix
Coluna 1
float: left; width: 33.33%
Coluna 2
float: left; width: 33.33%
Coluna 3
float: left; width: 33.33%

O container pai usa ::after { clear: both } — sem isso, sua altura colapsaria para zero, pois os floats não contam para a altura do pai. 

.float-img  { float: left; width: 120px; margin-right: 16px; }
.float-col  { float: left; width: 33.333%; }
.clearfix::after { content: ""; display: table; clear: both; }
03

Position

Controla como um elemento é posicionado em relação ao fluxo normal, a um ancestral posicionado, à janela de visualização ou ao seu próprio contêiner de rolagem.

static (padrão) vs. relative (deslocado do próprio lugar)
static — posição normal
relative — top:10px; left:20px

O relative desloca visualmente o elemento, mas o espaço original que ele ocuparia no fluxo continua reservado.

absolute — posicionado em relação ao ancestral relative
contêiner pai (position: relative)
absolute
top:10px; right:10px
sticky — gruda ao rolar dentro do contêiner
sticky — top: 8px (role esta caixa)
conteúdo de rolagem acima do sticky…
continue rolando — o rótulo acima gruda no topo…
…até o contêiner acabar.
mais conteúdo para forçar a rolagem interna do stage.

fixed não aparece isolado no stage porque seu efeito só faz sentido em relação à janela inteira — é o mesmo mecanismo usado no menu do topo desta página, que usa position: sticky para permanecer visível durante a rolagem. 

.pos-relative  { position: relative; top: 10px; left: 20px; }
.pos-absolute-wrap { position: relative; }
.pos-absolute  { position: absolute; top: 10px; right: 10px; }
.pos-sticky-el { position: sticky; top: 8px; }
.topnav        { position: sticky; top: 0; } /* fixed seria: position: fixed; top: 0; */

Flexbox

Layout unidimensional: distribui itens ao longo de um eixo principal (main axis) e os alinha em um eixo transversal (cross axis). Ideal para barras de navegação, cartões em linha e centralização.

.flex-justify { justify-content: space-between; }

.g1 { flex-grow: 1; } .g2 { flex-grow: 2; }
.o-first { order: -1; } .o-last { order: 5; }

Grid

Layout bidimensional: define linhas e colunas simultaneamente. Ideal para estruturas de página inteiras, galerias e qualquer layout que precise alinhar conteúdo em duas dimensões ao mesmo tempo.

Redimensione a janela: as colunas se ajustam automaticamente sem nenhuma @media. 

.grid-basic  { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }
.grid-tracks { grid-template-columns: 120px 1fr 2fr; }
.grid-areas  {
  grid-template-columns: 140px 1fr 1fr;
  grid-template-areas:
    "sidebar header header"
    "sidebar main    aside"
    "sidebar footer  footer";
}

.grid-autofit{ grid-template-columns: repeat(auto-fit, minmax(110px, 1fr)); }
